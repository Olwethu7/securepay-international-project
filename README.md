SecurePay International

SecurePay International is a real-time international payment settlement portal that allows users to send cross-border payments, monitor transaction statuses, and view a complete audit history.

What It Does

Send international payments – Supports multiple currencies (USD, GBP, ZAR, JPY, CAD, and more) with IBAN and SWIFT/BIC validation.

Real-time settlement monitoring – Watch live transaction status updates as payments process through the settlement network.

Full transaction history – Search, filter by date or status, sort columns, and expand any transaction to see SWIFT/BIC codes and payment reasons.

Export ledger data – Download the current filtered transaction list as a CSV file.

Mobile responsive – Works on desktop, tablet, and phone.

Key Features

Payment authorization with country-specific account validation

Status badges: Completed, Pending, Failed

Expandable transaction details (SWIFT/BIC + narrative)

Dashboard with live throughput and node telemetry

Secure login and registration
